# KODA.md — Контекст проекта Kanban Game

## Обзор проекта

**Kanban Game** — интерактивная симуляция канбан-процесса (Flow Process), реализованная как веб-приложение. Проект визуализирует поток задач через этапы производственной системы: **Ready → Analysis → Development → Testing → Done → Deployed**.

Симуляция использует механику игральных костей (dice) для моделирования производительности рабочих на каждом этапе. Приложение в реальном времени отображает три аналитических графика на Canvas:

- **Cumulative Flow Diagram (CFD)** — кумулятивная диаграмма потока, показывающая количество задач на каждом этапе по дням.
- **Control Chart (CC)** — контрольная диаграмма с скользящим средним (окно 5 задач), отражающая время цикла (cycle time).
- **Distribution Diagram (DD)** — диаграмма распределения времени цикла с расчётом 85-го перцентиля.

Проект предназначен для обучения принципам канбан-менеджмента, визуализации узких мест и анализа потока создания ценности.

## Архитектура

### Структура файлов

```
src/
├── index.js      — Точка входа. Инициализация Vue-приложения, рендеринг Canvas-диаграмм (CFD, CC, DD), управление состоянием игры.
├── board.js      — Класс Board. Ядро симуляции: управление колонками (этапами), генерация задач, логика хода (turn), перемещение карточек.
├── card.js       — Класс Card. Генерация карточек задач с оценками по этапам, отслеживание оставшегося объёма (remainings).
├── column.js     — Класс Column. Управление лимитами WIP, логика задержек (delay), проверка доступности для pull-операций.
├── dice.js       — Класс Dice. Генерация игральных костей с гранями для каждого этапа, расчёт результата броска (score).
├── util.js       — Утилиты (генерация случайных чисел).
└── index.scss    — Стили приложения, наследующие Bootstrap.

test/
├── test-board.js   — Тесты Board (перемещение карточек между колонками).
├── test-card.js    — Тесты Card (генерация задач).
├── test-column.js  — Тесты Column (WIP-лимиты, задержки, pull-логика).
├── test-dice.js    — Тесты Dice (генерация костей, расчёт очков).
└── test-util.js    — Тесты Util (случайные числа).
```

### Ключевые архитектурные решения

- **Двухфазная модель данных:** `Board` хранит состояние симуляции (`board.columns`, `board.utilization`, `currentDay`), Vue-компонент отображает данные через реактивные свойства.
- **Canvas-рендеринг:** Все три диаграммы рисуются вручную через Canvas 2D API (функции `drawCFD`, `drawCC`, `drawDD`, `drawGrid`, `ln`, `rr`).
- **Игровой цикл:** Метод `tickDown()` вызывает `board.turn()` каждую секунду при `isPlaying === true`, обновляя данные Vue через `$forceUpdate()`.
- **Модульность:** Бизнес-логика (Board, Card, Column, Dice) полностью отделена от UI и экспортируется через `module.exports`.

## Сборка и запуск

| Команда | Описание |
|---------|----------|
| `npm i` | Установка зависимостей |
| `npm run dev` | Сборка в режиме разработки (Webpack, вывод в `docs/`) |
| `npm run prod` | Продакшн-сборка (минификация, оптимизация) |
| `npm run start` | Запуск dev-сервера (Webpack Dev Server, порт 3000) |
| `npm run watch` | Режим наблюдения за изменениями файлов |
| `npm run lint` | Линтинг с автоисправлением (`eslint ./src ./test --fix`) |
| `npm run test` | Запуск тестов Jest |
| `npm run coverage` | Тесты с покрытием (отчёт `lcov`) |

### Конфигурация сборки

- **Точка входа:** `src/index.js`
- **Выходная директория:** `docs/` (содержит `index.html`, `index.js`, `index.css`)
- **Dev Server:** порт 3000, статика из `docs/`
- **Babel:** транспиляция через `@babel/preset-env` (исключая `node_modules`)
- **CSS:** обработка через `MiniCssExtractPlugin` + `sass-loader` + `css-loader`

### Конфигурация тестирования

- **Путь к тестам:** `test/**/*.[jt]s?(x)`, `**/?(*.)+(spec|test).[jt]s?(x)`
- **Отчёт покрытия:** `lcov`

## Правила разработки

### Стиль кодирования

- **Модульность:** Каждый класс в отдельном файле, экспорт через `module.exports`.
- **CommonJS:** используются `require()` и `module.exports` (не ES-модули).
- **ESLint:** конфигурация в `.eslintrc.js`, автоисправление через `--fix`.
- **SCSS:** переменные для цветовой палитры, вложенность через Bootstrap SCSS.

### Тестирование

- **Фреймворк:** Jest (без дополнительных зависимостей, используется npx).
- **Покрытие:** 5 тестовых файлов, покрывающих все модули ядра (`Board`, `Card`, `Column`, `Dice`, `Util`).
- **Подход:** тестирование публичных методов и статических функций. Тесты на `Board` минимальны (покрытие `move()`).

### Горячие клавиши (в приложении)

| Клавиша | Действие |
|---------|----------|
| **F** | Полноэкранный режим |
| **S** | Старт / Пауза симуляции |
| **R** | Сброс симуляции |

### CI/CD

- **GitHub Actions:** `nodejs.yml` — проверка сборки и тестов.
- **Codecov:** автоматическая загрузка отчёта о покрытии.
- **Codacy:** статический анализ кода.
- **GitHub Pages:** автоматический деплой через `publish.yml`.

## Важные замечания

1. **Vue 2:** проект использует Vue 2.6 (не Vue 3). При модификации UI учитывайте Options API и шаблонную синтаксическую структуру Vue 2.
2. **Ручной Canvas:** диаграммы рисуются без сторонних библиотек визуализации. Все функции отрисовки (`drawCFD`, `drawCC`, `drawDD`, `drawGrid`, `ln`, `rr`) находятся в `src/index.js`.
3. **Симуляция:** логика хода (`Board.turn()`) обрабатывает этапы в обратном порядке (от `deployed` к `ready`), что соответствует pull-системе канбан.
4. **Данные:** карточки имеют идентификаторы формата `S001`, `S002` и т.д. Оценки по этапам генерируются случайно: для Testing — 5–15 единиц, для остальных — 2–10.
5. **Зависимости:** Bootstrap 4.6 подключён как через SCSS, так и через JS (jQuery + Popper). При удалении Bootstrap потребуется пересмотреть стили и компоненты.
